# 公司查询 · 数据策略

对应 C1、C2、C4、C5。字段分必要 / 非必要；必要项缺失时对**允许的来源**重试，不允许的来源保持「暂无」。

## 所有制与规模（需求 1）

卡片必显 **类型**。取值互斥为主、可附加标记：

| 类型 | 判定（L1） | 特别标注 |
| --- | --- | --- |
| 国企 | Wikidata 国家控股 / 国有企业；或导入「央企/地方国企名录」命中 | **央企**单独徽章（对照国务院国资委公开央企名录，用户可导入该表） |
| 私企 | 非国有、非外资控股 | **大厂 / 中厂 / 小厂**：优先员工数（Wikidata），其次导入的营收或人数；阈值写进配置并在界面注明「按员工数分档，非工信部划型」 |
| 外企 | 总部或控股方在境外（Wikidata country / parent） | **外资归属**：国家或母公司名称 |
| 未知 | 以上都无法判断 | 类型显示「暂无」，不猜测 |

**编制**：非必要但用户强烈关心。事业编制/参公与「是不是央企」不是一回事。只来自 L2 导入（是 / 否 / 部分岗位）。L1 **不得**因为央企就写成「有编制」。

地方国企、央企子公司、混合所有制：类型用国企或「混合」，用备注说明，不发明第四套徽章除非导入表给了标签。

## 薪资（需求 2）

非必要。展示时必须带来源和年份。

| 层级 | 可以 | 不可以 |
| --- | --- | --- |
| L1 | Wikidata 若有薪酬相关声明（极少）；上市公司年报里的员工薪酬总额/人均（法定披露，注明「年报人均，非应届 offer」） | 把董监高薪酬当成校招生薪资 |
| L2 | 学校《就业质量报告》、学院统计、自己整理的 offer 表 | — |
| L3 | 以后若有授权薪酬 API | 爬 BOSS、看准、脉脉、职友集 |

没有则卡片不写或写「薪资 暂无」。

## 岗位与按专业/岗位检索（需求 3、5）

岗位是独立表，一家公司多条。每条尽量有：岗位名、专业标签、地点、学历、届别。

检索类型在选刊的「智能 / 名称 / 行业 / 代码」上增加：

- **专业**：词表把「光学工程」「集成电路」展开到岗位关键词（工艺、光学设计、模拟 IC…），再落到有这些岗位的公司。
- **岗位**：直接匹配岗位名。

地点：岗位上的城市/职场；没有岗位时退回公司总部（Wikidata），并标明「总部，非岗位地」。

岗位正文默认 L2 导入校招表。若做 L1：仅用户点击「从该公司官网招聘页更新」，且只解析对方公开页面，失败则暂无。不把实习僧/海投网当默认同步源。

## 秋招 / 春招（需求 4）

表 `recruitment_rounds`：公司、年份、季节（秋招/春招/暑期实习）、开始日期、结束日期、计划人数、实际人数（常缺）、来源。

有则在卡片和筛选里用；缺起止或人数就该项暂无，不补假日期。往届多条按年份倒序。

## 财政、债务、官司（需求 6）

| 内容 | L1 | L2 | 没有时 |
| --- | --- | --- | --- |
| 财政 | 上市公司：营收、净利、资产负债率等，来自交易所/法定披露（能解析的年份） | 用户粘贴的年报摘录 | 「非上市或未同步，暂无」 |
| 债务 | 年报中的有息负债、债券违约公告（披露文件） | 导入备注 | 暂无 |
| 官司 / 纠纷 | 不默认同步裁判文书全库 | 导入「有诉讼/失信」标记及案号链接 | 暂无；**不**显示编造的「风险指数」 |

未上市小厂没有法定年报的，财政与官司以导入为准。不要用爬取的天眼查「司法案件数」充官方。

## 密切高校（需求 7）

| 信号 | 来源 | 展示 |
| --- | --- | --- |
| 合作论文、共同作者单位 | OpenAlex（机构 ↔ 公司别名/资助） | 「与某某高校共同发表 n 篇 · OpenAlex」 |
| 成立/持股/所在地高校 | Wikidata | 有则列出 |
| 就业基地、实习协议、校友企业 | L2 导入 | 标签「就业基地 · 某校 2025」 |

无信号则不显示「密切高校」，避免空挂名校。

## 三层总表

| 层级 | 字段 | 来源 | 缺失 |
| --- | --- | --- | --- |
| L1 | 名称、别名、官网、总部、行业、QID、ticker、所有制粗分、员工数、外企归属 | Wikidata | 不收录或该项暂无 |
| L1 | 上市财务要点 | 法定披露 | 暂无 |
| L1 | 密切高校（论文/资助） | OpenAlex | 不显示 |
| L1′ | 官网招聘（可选、用户触发） | 公司自己的招聘页 | 岗位暂无 |
| L2 | 信用代码、编制、央企名录、校招岗、届别人数、地点、薪资摘录、诉讼备注、就业基地 | CSV/xlsx | 暂无 |
| L3 | 面经、股权穿透、实时 offer | 不默认同步 | 隐藏 |

## 红线

- 不把天眼查、企查查、BOSS、脉脉、看准当默认同步源。
- 不把员工数写成注册资本，不把年报人均薪酬写成「应届薪资」。
- 不把国企自动标成「有编制」。
- 每一项旁标注来源和年份。

## 匹配键（导入）

1. 统一社会信用代码  
2. 股票代码  
3. Wikidata QID  
4. 规范化名称  

对不上计入未匹配，不凭空建公司。校招岗位表允许「先有公司再挂岗」；公司尚未入库时岗位行算未匹配。

## 导入表示例列

公司表：`name`、`qid`、`ticker`、`credit_code`、`ownership`（国企/央企/私企/外企）、`bianzhi`（编制）、`size_band`、`foreign_origin`、`salary_note`、`year`

岗位/校招表：`name` 或 `ticker`、`job_title`、`major`、`city`、`season`（秋招/春招）、`start`、`end`、`headcount`、`year`

纠纷表：`name`、`case_type`（诉讼/仲裁/失信）、`summary`、`url`、`year`

高校表：`name`、`university`、`relation`（就业基地/联合实验室/校友企业）

## 建议表结构

- `companies`：身份、官网、总部、QID、ticker、所有制、规模档、外资归属
- `company_industries`
- `company_jobs`：岗位、专业标签、地点
- `recruitment_rounds`：秋招春招届别
- `company_finance`：按财年存披露指标
- `company_disputes`：导入的纠纷摘要
- `company_universities`：密切高校及关系类型
- `company_notes` / `company_import_batches`

与 `journals` 同库不同表。
