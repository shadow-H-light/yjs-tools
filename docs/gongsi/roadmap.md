# 公司查询 · 开发计划

口径：套选刊节奏。插件不做。G0–G5 先做出能用的公司档案与分类；G6–G8 补校招岗位、财务纠纷、密切高校（都在同一模块里，不另开产品）。

单人大约 8–10 周。

## 总览

| ID | 名称 | 大约 | 验收 |

## 分里程碑

### G0 模块壳

顶栏、空 API、`xuankan gongsi --help`。不改选刊行为。

### G1 公司库 + 分类

- Wikidata 同步：官网、QID、ticker、国家、员工数、总部、行业。
- 规则引擎打标：国企 / 私企 / 外企；员工数 → 大中小厂；境外控股 → 外资归属。
- 导入「央企名录」命中则打 **央企** 徽章。
- 编制字段存在但不自动填。

验收：搜到华为等常见雇主；类型徽章正确或为暂无；不出现「央企=有编制」。

### G2 导入器

支持多 `kind`：公司主表、央企名录、编制、薪资摘录。未导入不显示假信用代码、假编制、假薪资。

### G3 行业·专业·岗位匹配

- 行业词 + 专业词表（光学工程 → 光学/工艺等岗位关键词）。
- 无岗位数据时专业检索只能打到行业近似，并提示「尚未导入岗位表」。
- 无向量时标明「当前是行业/专业词匹配」。

### G4–G5

对比表增加类型、地点、编制、薪资（空则暂无）。写出 usage。

### G6 校招岗位与届别

- `company_jobs`、`recruitment_rounds`。
- 导入校招 xlsx：岗位名、专业、城市、季节、起止、人数。
- 筛选：专业、岗位、地点、秋招/春招、年份。
- 可选：对已有官网招聘 URL 的公司做一次用户触发的解析（失败则停）。

验收：导入一张样例校招表后，用「光学工程」能筛到对应公司，卡片上能看到城市和起止日期。

### G7 密切高校

OpenAlex 合作/资助信号 + 导入就业基地。无信号不展示该块。

### G8 上市财务与纠纷

- 仅对有 ticker 的公司尝试公开披露要点（营收、净利等），失败则暂无。
- 纠纷只接受导入或以后的授权接口。界面注明「非天眼查」。
