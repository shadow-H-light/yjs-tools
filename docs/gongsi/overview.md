# 公司查询 · 概述

本机上的企业与校招筛选工具：先按所有制、行业、专业/岗位找到公司，再看地点、往届校招、公开财务与风险、密切高校。

只查询、只对比，不投递。默认跑在自己电脑上，和选刊神器共用同一个本机服务。插件先不做。

商业征信网站（天眼查等）仍不爬；能从**公开知识库、上市公司法定披露、用户导入的校招表**拿到的，都尽量写入并标明来源。拿不到的显示「暂无」，不编造。

## 用户能做什么

检索：

1. 公司名、股票代码、行业、地名。
2. **专业**（如光学工程、集成电路）、**岗位**（如工艺工程师、嵌入式）。
3. 筛选所有制（国企 / 私企 / 外企）、是否央企、私企规模档、工作地点、秋招/春招届别。

卡片上能看到：

4. **分类**：国企（央企单独角标；编制有数据才写，没有则「暂无」，不根据「国企」臆断有编制）、私企（大/中/小厂）、外企（外资归属国或母公司）。
5. 官网、编号、行业、**岗位地点**。
6. **薪资**：有公开或导入的区间才显示，并写来源；没有则隐藏或「暂无」。
7. **往届秋招/春招**：起止时间、招录人数（有则显示）。
8. **财政与纠纷**：上市公司公开财报要点；债务/官司有公开或导入才显示。
9. **密切高校**：联合发文、资助、就业基地等，标明来源。

操作：勾选 2–4 家对比，导出 CSV；导入校招简章、就业质量报告摘录、国资委央企名录等自己有权使用的表。

## 七项需求如何落地（摘要）

| 需求 | 尽量自动拿 | 导入补全 | 绝不做 |
| --- | --- | --- | --- |
| 1 分类（国企/私企/外企、央企、编制、规模） | Wikidata 所有制与国家；员工数分档；可选导入「央企名录」打标 | 编制、注册资本分档 | 把子公司一律标成有编制 |
| 2 薪资 | 仅当公开披露或 Wikidata 有声明 | 就业质量报告、学校统计表 | 爬 BOSS/看准/脉脉 |
| 3 岗位 + 按专业/岗位搜 | 公司官方招聘页若可结构化则本机拉取（用户触发） | 校招简章、岗位表 | 爬实习僧/海投网当默认同步 |
| 4 秋招春招起止与人数 | 同上，能解析则存 | 往届通知 PDF/表格 | 编造人数 |
| 5 岗位地点 | 岗位记录上的城市；Wikidata 总部作补充 | 工作地点列 | 用总把所有岗位标成北京 |
| 6 财政、债务、官司 | 上市法定披露（营收、净利、有息负债等） | 诉讼/失信摘录 | 爬天眼查诉讼列表冒充官方 |
| 7 密切高校 | OpenAlex 合作发文/资助；Wikidata | 就业基地、校友企业名单 | 无来源的「关系户」 |

## 和选刊神器的对应关系

| 选刊 | 公司查询 |
| --- | --- |
| OpenAlex 同步期刊 | Wikidata 同步企业 + 上市公司披露 |
| ISSN / OpenAlex ID | QID、股票代码；信用代码靠导入 |
| JCR 表 | 央企名录、校招表、就业质量报告 |
| 主题 Topic | 行业 + 专业/岗位词表 |
| 影响因子 | 不编造薪资/市值；有来源才显示 |
| 审稿时长（可空） | 编制、校招人数、官司（可空） |

## 明确不做

- 代投、自动网申。
- 网站、云同步、多用户。
- 默认同步或抓取天眼查、企查查、启信宝、领英、BOSS、脉脉、看准。
- 用估算薪资、估算编制冒充官方。
- 另起端口或另一套 UI。
- 本期做插件。
