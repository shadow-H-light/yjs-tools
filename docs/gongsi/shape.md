# 公司查询 · 产品形态

对应决策 C3（沿用本地版）和 C4（本机第二模块）。选刊的插件二期仍然后置。

## 一句话

不是新网站。是选刊神器同一个本机进程里多出来的「公司」页：检索框、工具条、结果卡片、对比表都复用现有样式。

## 怎么用

```text
本机数据（同一 SQLite：journals + companies）
        ↑
   FastAPI（仍只监听 127.0.0.1:8765）
        ↑
   本地网页：顶栏切换 选刊 | 公司
```

1. 还是 `uv run xuankan serve`（或以后的 `yjs serve` 别名）。
2. 浏览器打开同一地址，点「公司查询」。
3. 同步公开企业、导入校招/央企名录、按专业或岗位检索、对比导出。

CLI 增加并列命令，不另做一个 exe：

```text
xuankan serve
xuankan gongsi ingest
xuankan gongsi import 名单.xlsx
xuankan gongsi search 光学工程 --by major
xuankan gongsi compare 1,2
```

选刊原有 `ingest` / `import` / `search` 保持不变，避免同学脚本坏掉。

## 体积怎么压住

| 要 | 不要 |
| --- | --- |
| 同一端口、同一套 CSS | 第二套设计系统、第二端口 |
| 公司表加在现有 SQLite | 默认再开 PostgreSQL |
| 用户点「同步 Wikidata」「导入名单」 | 常驻爬虫、工商全量镜像 |
| 结果列表 + 对比表 + 岗位/届别筛选 | 股权图谱、天眼查式风险雷达 |

## UI 套用（必须长得像选刊）

- 背景、卡片、按钮、必填字段网格（`required-facts`）沿用 `web/src/styles.css`。
- 顶栏：左上模块名 + `v0.1`，模块切换做成两个文字按钮，不要新导航框架。
- 搜索卡：类型（智能 / 名称 / 行业 / 代码 / **专业** / **岗位**）+ 检索框。
- 筛选：国企/私企/外企、央企、规模档、地点、秋招/春招年份。
- 工具条：同步、导入（公司名单 / 岗位校招表）、对比已选、导出。
- 卡片必显：类型（含央企角标、外企归属、私企规模档）、官网、编号、行业、所在地/岗位地。
- 有则显示：编制、薪资（带来源）、本届/往届校招起止与人数、财务要点、纠纷、密切高校。无则「暂无」或隐藏。
- 空态、错误、进行中条幅的文案语气与选刊一致。

## 和其他模块

导师、学校、就业以后同样是顶栏新模块，不是新仓库。公司查询先把「模块切换 + 共用 serve」这条路趟平。
