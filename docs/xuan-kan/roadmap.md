# 选刊神器 · 开发计划

口径：单人大约 9 周。按 D3/D4：本机 FastAPI + SQLite + 薄网页，插件放二期。

## 总览

| ID | 名称 | 时间 | 验收 |
| --- | --- | --- | --- |
| M0 | 基建 | 第 1 周 | `serve` 能在本机起来，打开空控制台 |
| M1 | 期刊库 | 第 2–3 周 | 本机同步国际刊后能搜、能打开详情 |
| M2 | 导入器 | 第 4–5 周 | 选本地 CSV 导入分区/IF，筛选正确 |

## 分里程碑

### M0 基建

- `uv` 初始化 Python 包，CLI：`serve`。
- FastAPI 只绑 `127.0.0.1:8765`。
- SQLite 空库 + 迁移。
- Vite 空页面，开发时独立端口，生产构建进 FastAPI 静态目录。
- `data/` 写入 `.gitignore`。

不装 PostgreSQL、Docker、登录、Next.js。还没有期刊数据。

### M1 期刊库

- 命令或控制台按钮：从 OpenAlex 拉有 ISSN 的 journal。
- 刊名 / ISSN / 缩写检索（SQLite FTS）。
- Topic 筛选与详情（主页、出版社、开放引用）。

验收：本机演示「同步一次 → 搜得到 → 点得开」。先求常用国际刊能用，不追求一次全历史。

### M2 导入器

- 控制台选本地 CSV：ISSN + 年份 + JCR Q / IF / 中科院分区。
- `import_batches` 记下文件名和年份。
- 未导入时不显示假 IF，官方筛选不可用。

验收：导入样例表后筛选与表一致；删掉该批次后官方指标消失。

### M3 方向匹配

- 关键词 → Topic + 刊名。
- 若本机有 embedding，再加上 scope 向量；没有则明确提示「当前是主题匹配」。
- 列表展示命中主题。

验收：输入具体方向能出相关刊，不是只搜刊名字符串。

### M4 审稿与对比

- 审稿时长可导入、可空。
- 对比 2–4 刊，导出 CSV 到本机。

### M5 打磨

- README：如何 `serve`、如何同步、如何导入。
- 失败提示写清楚（网络、CSV 列不对、库文件锁）。
- 给同学的安装说明：克隆、`uv sync`、一条命令。

### 二期 · 插件

- 冻结本机 API（OpenAPI）。
- 选 Zotero 或浏览器扩展开做一个最小客户端。
- 本机没启动时提示去开服务，插件不自己抓网。
