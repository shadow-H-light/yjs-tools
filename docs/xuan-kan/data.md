# 选刊神器 · 数据策略

对应决策 D1（先做国际刊）、D2（只做导入器）和 D4（数据只留在本机）。

## 三层数据

| 层级 | 字段 | 来源 | 怎么进库 | 没有数据时 |
| --- | --- | --- | --- | --- |
| L1 本机同步 | 刊名、ISSN、出版社、OA、主页 | OpenAlex Sources、Crossref | 用户在本机触发拉取，写入 SQLite | 不收录该刊 |
| L1 本机同步 | 学科 / 主题 | OpenAlex Topics（Domain → Field → Subfield → Topic） | 随期刊同步进本机库 | 不参与主题召回 |
| L1 本机同步 | 引用次数、两年篇均被引 | OpenAlex `cited_by_count` / `2yr_mean_citedness` | 随期刊同步进本机库 | 该项显示「暂无」 |
| L2 导入器 | JCR 分区、IF、五年 IF | 用户或运营导入的授权表 | CSV / 约定格式文件，带年份 | 筛选器隐藏或灰掉，不假装有官方 IF |
| L2 导入器 | 中科院分区、预警名单 | 官方发布文件或已获授权副本 | 同年份一张表 | 同上 |
| L3 可缺失 | 审稿时长、接收率 | 期刊官网声明、后期人工表 | 先覆盖高频刊 | 显示「暂无」，不编造 |

L1 由用户在本机触发同步，不设云端期刊库。L2 是选本地文件导入，不是爬虫。L3 允许长期空着。

库文件就在本机（如 `data/xuankan.sqlite` 或用户目录）。备份、拷给同学 = 复制该文件和导入用的 CSV。

## 红线

- 不要把 JCR、中科院分区当默认同步源。
- 不要抓 LetPub、Web of Science、知网再二次分发。
- 开放引用指标可以展示，名称不要写成「影响因子」。
- 每一项指标旁标注来源和年份，例如「开放引用 · OpenAlex 2026」「中科院分区 · 2025 导入」。

中科院分区系列已不再持续更新。导入器按「年份 + 来源」存多份，筛选时让用户选正在使用的版本。

## CSV 格式

第一行是表头，UTF-8。ISSN 必填，用来匹配本机已同步的期刊；匹配不上的 ISSN 会计入未匹配，不会凭空建刊。

| 列名（任选一种） | 含义 |
| --- | --- |
| `issn` / 刊号 | 带或不带连字符均可 |
| `year` / 年份 | 可省略，若省略须在导入时指定年份 |
| `jcr_quartile` / `jcr_q` / JCR分区 | `Q1` 或 `1` |
| `impact_factor` / `if` / 影响因子 | 数字 |
| `impact_factor_5` / `if5` / 五年影响因子 | 数字，可空 |
| `cas_quartile` / 中科院分区 | `1` 或 `一区` |
| `warning` / 预警 | `1` / `是` / `预警` |

样例（示意数字，不是官方值）：

```bash
uv run xuankan import examples/metrics-sample-2025.csv --year 2025 --source sample
```

## 关键词如何落到期刊

召回三条路，合并去重后再过滤、排序。

1. **刊名**：全文 + 三元组，覆盖 ISSN、缩写、常见拼写误差。
2. **主题**：关键词映射到 OpenAlex Topic，取该主题下的刊。
3. **语义（可选）**：对 aims/scope 做向量检索。本机没装 embedding 时跳过，只走 1、2。

排序：

- 匹配分 = 主题重合 + 语义相似度
- 质量分 = 分区（有导入时）+ 开放引用指标 − 预警
- 必须解释：列出命中的主题词，避免黑盒推荐

## 建议表结构

SQLite 一张库。语义如下。

- `journals`：身份、ISSN、出版社、主页、OA
- `journal_topics`：期刊与主题多对多
- `journal_metrics`：按年份存 IF、分区、引用
- `journal_scope`：范围文本；embedding 列可空
- `journal_flags`：预警、掠夺性、OA 等标记
- `import_batches`：哪一个本地文件、哪一年、何时导入
