# 选刊神器 · 概述

本机上的国际刊筛选工具：按方向匹配，再按分区、指标、审稿时长对比。

只筛选、只匹配，不投稿。默认跑在自己电脑上，不是网站。

## 用户能做什么

1. 本机启动后，用刊名、主题、ISSN 查找国际刊与中文刊。
2. 看分类、引用、（导入后的）分区与影响因子、（有数据时的）审稿时长。
3. 输入研究方向或关键词（中英文均可），得到按匹配度排序的期刊，并看到命中了哪些主题。
4. 可指定搜索类型：智能 / 刊名 / 主题 / ISSN。
5. 按分区、收录范围筛选，勾选 2–4 本刊对比。
6. 从本机选择 CSV，导入自己有权使用的分区/IF 表。

二期：在 Zotero 或浏览器里调用同一个本机服务。

## 明确不做（第一期）

- 代投、自动投稿、账号登录出版社。
- 做成需要注册的网站、云同步、多用户后台。
- 默认同步 JCR / 中科院官方全表，或抓取 Clarivate、LetPub、知网。
- 用估算分区冒充官方分区。
- 默认依赖 Docker / PostgreSQL 才能启动。
- 一次做完导师、学校、就业、公司四个工具。
- 第一期就做插件（API 先稳定）。

## 和 yjs-tools 的关系

选刊神器是第一个**本机工具**。后面的模块优先加成同一本地服务里的新命令或新路由，而不是做成一个大应用。
